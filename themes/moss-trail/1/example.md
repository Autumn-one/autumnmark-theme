# 苔径 · Moss Trail

午后的薄雾沿山脊散开。石阶上的青苔还湿着，我们放慢脚步，记下林中几处可以停留的地方。

> 雾散之前，先听听树与水的声音。

## 步道札记

| 地点 | 观察 | 标记 |
| :--- | :--- | :--- |
| 杉木坡 | 石阶上覆着柔软的苔藓 | 起点 |
| 林间浅溪 | 水线很低，能看见鹅卵石 | 歇脚 |
| 旧桥边 | 雾后有一线斜阳 | 折返 |

- 从 **杉木坡** 出发，过溪后沿缓坡向南。
- 把 *旧桥* 设为折返点，留好回程时间。

```js
const trail = { name: "Moss Trail", distance: 4.2 }
console.log(trail.name)
```
